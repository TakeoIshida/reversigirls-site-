Reversigirls

プライバシーポリシー

制定・最終更新日：2026年10月25日

Takeo Ishida（以下「開発者」）は、iOSアプリ「Reversigirls」（以下「本アプリ」）における情報の取り扱いを、以下のとおり説明します。

1. ゲームのデータ

本アプリはアカウント登録を必要としません。戦績、キャラクターの解放状況、チュートリアルの完了状況、各種設定など、ゲームの継続に必要なデータを端末内に保存します。

本アプリは、氏名、住所、電話番号、連絡先、写真ライブラリ、マイク、カメラ、GPSによる正確な位置情報へのアクセスをゲーム機能として要求しません。

2. 広告配信と同意情報

本アプリにはGoogle AdMob（Google Mobile Ads SDK）と、プライバシーの選択を管理するUser Messaging Platform（UMP）SDKが組み込まれています。広告の読み込み・表示や同意情報の確認のため、Google等への通信が行われます。

広告SDKは、IPアドレスとそれに基づくおおよその地域、端末・アプリに関する識別情報、広告の表示・操作情報、アプリとの操作に関する情報、クラッシュや性能などの診断情報を収集・処理する場合があります。取得範囲はSDK、端末設定、地域、ユーザーの選択等により異なります。

3. 利用状況の計測

本アプリは、ゲーム内容の改善と広告配置の評価のためにGoogle Firebase Analyticsを使用します。対戦の開始・終了、勝敗、選択したキャラクター、チュートリアル完了、ヒントやリワード広告の利用など、個人を直接特定しない操作情報を記録します。氏名、メールアドレス、自由入力文などをイベントとして送信しません。

Firebase Analyticsは、端末やアプリに関する情報、利用状況、診断情報等を処理する場合があります。詳しくはGoogleの説明をご確認ください。

  • Google プライバシーポリシー
  • Googleのサービスを使用するサイトやアプリから収集した情報の使用
  • Google Mobile Ads SDKのデータ収集に関する説明
  • Firebaseのプライバシーとセキュリティ

4. ユーザーの選択

地域等に応じて、広告に関する同意画面を表示します。再選択が必要な地域では、本アプリ内の「プライバシー」から選択内容を変更できます。同意を拒否してもゲームの基本機能は利用できますが、広告の利用状況によっては動画視聴による特典を利用できない場合があります。

本アプリは、AppleのApp Tracking Transparency（ATT）に基づいてトラッキングの許可を求める場合があります。許可しない場合、広告識別子IDFAを利用したトラッキングは行いません。iOSの「設定」から選択を変更できます。

5. Game Center

ランキング等の機能にはApple Game Centerを使用します。Game Centerに関する情報はAppleのアカウントと設定に基づいてAppleが処理します。詳しくはAppleのプライバシーポリシーをご確認ください。

6. 保存と削除

端末内のセーブデータはゲームの継続のために保持します。iOSの「Appを削除」により本アプリを削除すると、通常は端末内のアプリデータも削除されます。「Appを取り除く」ではデータが保持される場合があります。OSのバックアップ・復元機能による取り扱いはAppleの設定および仕様に従います。

GoogleやApple等へ送信済みの情報は、アプリを削除しても自動的に削除されるとは限りません。各事業者のプライバシーポリシーと管理手段をご確認ください。

7. お問い合わせ

本アプリについての一般的なご質問は、開発者が管理するサポート窓口（GitHub Issues）へ、件名に「Reversigirls」と記載してお寄せください。投稿にはGitHubアカウントが必要です。

GitHub Issuesの投稿は公開されます。氏名、メールアドレス、広告識別子、パスワード等の個人情報・機密情報を投稿しないでください。

8. このWebページについて

このページはGitHub Pagesで配信しています。閲覧時には、配信・保護のためにGitHubがIPアドレス等を処理する場合があります。このページ独自の広告、アクセス解析スクリプト、入力フォームは設置していません。詳しくはGitHubのプライバシーに関する声明をご確認ください。

9. 改定

本アプリの機能や情報の取り扱いの変更等に応じて本ポリシーを改定することがあります。改定時は本ページに新しい内容と更新日を掲載し、必要に応じてアプリ内でお知らせします。
